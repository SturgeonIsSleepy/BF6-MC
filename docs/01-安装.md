# 逐步安装

## 0. 前置检查

```
java -version        → 必须是 17.x
```

Forge 40.2.21 只跑在 Java 17 上。Java 8 或 21 都会崩。

---

## 1. 建实例

推荐 PrismLauncher（能锁 Forge 版本、能一键导出整合包）：

1. `Add Instance` → `1.18.2` → `Forge` → 选 **40.2.21**
2. 内存：**6 GB**（`Settings → Java → Maximum memory`）
3. JVM 参数建议：

```
-XX:+UseG1GC -XX:MaxGCPauseMillis=50 -XX:G1HeapRegionSize=4M
-XX:+UnlockExperimentalVMOptions -XX:+ParallelRefProcEnabled
```

---

---

## 3. 放脚本

复制：

```
bf6/kubejs/server_scripts/*.js
   ↓
.minecraft/kubejs/server_scripts/
```

**8 个文件必须全放**，缺任何一个都会导致后续脚本报 `undefined is not a function`（因为跨文件引用函数）。

顺序无所谓（KubeJS 按文件名排序加载，`00_` 到 `07_` 已经排好）。

---

## 4. 放菜单资产

```
bf6/fancymenu/assets/*.png
   ↓
.minecraft/config/fancymenu/assets/
```

然后按 `fancymenu/README.md` 在游戏里搭布局。

---

## 5. 放配置

```
bf6/config/*.toml
   ↓
.minecraft/config/
```

配置项说明见 `config/README.md`。

---

## 6. 验证

启动游戏 → 进单人 → 创建新世界（创造模式，超平坦，关结构生成，关奖励箱）。

进世界后应该：

1. 被传送到 y=200 的虚空石台
2. 屏幕右上出现 sidebar，显示 `状态 大厅`
3. 底部 actionbar 显示 `[BF6] 地图 未选择 | 模式 未选择 | 准备 0/1`

如果没传送 → KubeJS 脚本没加载，看日志 `logs/kubejs/server.log`。

## 7. 联机

### 方案 A：e4mc（最省事，1-3 人）

1. 装 `e4mc`（1.18.2 Forge）
2. 主机进单人世界 → `对局域网开放` → e4mc 自动给一个 `xxx.e4mc.link` 域名
3. 朋友在多人里直连这个域名

⚠️ e4mc 只转发 TCP，**Simple Voice Chat 的 UDP 24454 不走这条链路**。要语音就得用方案 B。

### 方案 B：专用服务器（推荐）

1. 下 Forge 40.2.21 installer → `--installServer`
2. 把 `.minecraft/mods/` 整个复制到服务端 `mods/`
3. 把 `kubejs/` 整个复制到服务端根目录
4. `server.properties`：

```properties
online-mode=true
view-distance=8
simulation-distance=6
max-players=8
allow-flight=true          # IV 直升机需要
spawn-protection=0
```

5. 防火墙放行：
   - **TCP 25565**（游戏）
   - **UDP 24454**（语音）

6. 启动脚本见 `config/start-server.bat`

### 方案 C：ZeroTier / Tailscale

组虚拟局域网，直接内网 IP 直连。语音也能走，不用端口映射。

## 8. 常见问题

| 症状 | 原因 | 修法 |
|---|---|---|
| 进世界没传送到大厅 | KubeJS 没加载 | 看 `logs/kubejs/server.log`，确认 8 个脚本都 loaded |
| `/bf6` 命令不存在 | `01_maps_lobby.js` 没加载 | 同上 |
| sidebar 空白 | `07_hud.js` 没加载，或 `bf6_sidebar` objective 被别的插件占用 | `/scoreboard objectives list` 检查 |
| 右键讲台没反应 | 讲台坐标不对（`block.y !== 200`） | 确认大厅建在 y=200 |
| 进对局后卡在虚空 | 地图坐标没标定 | 见 `02-地图标定.md` |
| AI 不生成 | `recruits:recruit` 实体 ID 不对 | `/summon recruits:` Tab 补全确认 |
| 枪给不出来 | TaCZ 枪械 ID 不对 | `/give @s tacz:modern_kinetic_gun` 看实际 ID |
| 载具召不出来 | IV 实体 ID 不对 | `/summon iv:` Tab 补全 |
| 语音连不上 | UDP 24454 没放行 | 检查防火墙 / 路由器 |
| 一进服就崩 | Forge 版本不对 | 必须 40.2.21 |
