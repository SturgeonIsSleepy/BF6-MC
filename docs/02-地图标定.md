# 地图标定

`kubejs/server_scripts/bf6.js` 里 4 张地图的坐标是**设计值**，用来先跑通流程。要真正能玩，需要把地形建出来，或者把坐标改到你已有的地图上。

---

## 方案 A：自建 4 张图（推荐，可控）

四张图都在 **同一个 overworld** 里，用区块中心隔开，互不干扰：

| 地图 | 中心坐标 | 建议半径 | 地形 |
|---|---|---|---|
| urban 港区 | `8000 8000` | 250 | 城市 + 码头 |
| desert 沙海 | `16000 16000` | 350 | 沙漠 + 公路 |
| alpine 雪线 | `24000 24000` | 300 | 雪山 + 桦树林 |
| industrial 货柜场 | `32000 32000` | 200 | 集装箱 + 厂房 |

### 快速建图（WorldEdit / FAWE）

```bash
# 港区：铺一层沥青
//pos1 7880,60,7880
//pos2 8120,60,8120
//set gray_concrete

# 建筑：用结构方块或 //paste 贴预制楼
//schem load building1
//paste -o
```

### 标定出生点

站到红队出生位置，面向敌方，执行：

```
/bf6 mark spawn bf6_red
```

（这个命令**还没实现**——目前的替代做法是直接改脚本里的坐标数字，或者用 F3 看坐标手抄。）

改完重启服务器，`/bf6 start conquest` 验证。

## 方案 B：用现成地图

如果你有喜欢的 BF 风格地图（比如 Hypixel 的 Battlefield 图），可以直接用：

1. 把地图丢进 `saves/` 或服务器 `world/`
2. 读出出生点和占领点的实际坐标
3. 改 `bf6.js` 里对应地图的 `spawns` 和 `flags`
4. 把 `WORLD` 常量改成那张图的维度（如果是 overworld 就不用改）

```js
// 改这里
var WORLD = 'minecraft:overworld'

urban: {
    spawns: {
        bf6_red:  { x: -240, y: 72, z: 15,  yaw: 90 },
        bf6_blue: { x: 240,  y: 72, z: -15, yaw: -90 }
    },
    flags: [
        { id: 'A', x: -80, y: 70, z: 0, r: 14, name: 'A 点' },
        { id: 'B', x: 0,   y: 70, z: 0, r: 12, name: 'B 点' },
        { id: 'C', x: 80,  y: 70, z: 0, r: 14, name: 'C 点' }
    ],
    // ...
}
```

---

## 占领点半径怎么定

`r` 是**球形半径**（三维距离），不是圆形平面半径。

- `r = 12`：一个 24×24 的房间，适合室内点
- `r = 14`：一个中型广场
- `r = 16`：开阔地，需要载具才能快速转点

⚠️ 如果点设在建筑里，`r` 太大会把楼上/楼下也算进去。这种情况把 `y` 设在楼层中心，`r` 设小一点。

---

## 大逃杀缩圈参数

```js
br: { cx: 8000, cz: 8000, r0: 220, rEnd: 40 }
```

- `cx/cz`：缩圈中心
- `r0`：初始半径（玩家跳伞散布范围 = `r0 × 0.75`）
- `rEnd`：最终半径

5 段缩圈，每段 120 秒。1-3 人局建议 `r0 = 200~250`，再大跑图太累。

## 载具刷新点

```js
vehicles: [
    { type: 'iv:mtank', x: 8100, y: 70, z: 8020 },
]
```

`type` 必须是实际存在的实体 ID。用 `/summon iv:` 按 Tab 看有哪些。

常见的（取决于装了哪个内容包）：

```
iv:mtank      主战坦克
iv:car        民用/军用汽车
iv:heli       直升机
iv:truck      卡车
iv:plane      固定翼
iv:boat       船
```

如果 ID 不对，`/summon` 会报 "Unknown entity"，脚本里的 `runCommandSilent` 会静默失败，游戏里就是"没刷出载具"。
