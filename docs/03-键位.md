# 键位方案

1.18.2 + 这一堆 mod，默认键位会撞车。下面是一套验证过的方案，全部在 **`选项 → 控制 → 按键绑定`** 里改，各 mod 有自己的分类页。

---

## 冲突根源

| mod | 默认占用 | 和谁冲突 |
|---|---|---|
| ParCool | 左 Alt（滑铲）、左 Ctrl（翻滚）、R（抓墙） | 原版潜行/疾跑/交换副手 |
| TaCZ | R（换弹）、鼠标右键（瞄准）、V（检视） | 原版交换副手 / 放置方块 |
| Simple Voice Chat | V（语音菜单）、N（静音） | TaCZ 检视 |
| IV 载具 | C（自由视角）、Ctrl（脱离相机） | 原版潜行 |
| Recruits | 无默认键（全 GUI） | — |

---

## 推荐方案

### 移动（原版）

| 功能 | 键 |
|---|---|
| 前进/后/左/右 | `W A S D` |
| 跳跃 | `空格` |
| 潜行 | `Shift`（**保持原版**） |
| 疾跑 | `左 Shift 双击` 或改到 `R` |

### 战斗（TaCZ）

| 功能 | 键 | 说明 |
|---|---|---|
| 开火 | `鼠标左键` | 默认 |
| 瞄准 | `鼠标右键` | 默认 |
| 换弹 | `R` | 会和原版"交换副手"冲突 → 把原版交换副手改到 `F` |
| 切换射击模式 | `B` | |
| 检视武器 | `鼠标中键` | 避开 SVC 的 V |
| 近战/枪托 | `F` | 和原版交换副手错开 |
| 装/卸配件 | `G` | |

### 机动（ParCool）

| 功能 | 键 | 说明 |
|---|---|---|
| 滑铲 | `左 Ctrl` | 改掉默认的左 Alt，Alt 在 Windows 里会触发菜单 |
| 翻滚 | `左 Alt` → 改到 `C` | |
| 翻越 | `空格`（自动） | ParCool 的翻越是自动触发，不用绑 |
| 蹬墙跳 | `空格`（贴墙时） | 自动 |
| 抓墙/悬挂 | `Shift`（贴墙时） | 自动 |
| 攀爬 | `W`（对着梯子/藤蔓） | 自动 |
| 开关 ParCool | `右 Shift` | |

⚠️ ParCool 的很多动作是**上下文自动触发**的，不需要单独按键。真正要绑的只有：滑铲、翻滚、开关。

### 载具（Immersive Vehicles）

IV 的键位是**进载具后才生效**的，不占原版槽位。

| 功能 | 键 |
|---|---|
| 油门/刹车 | `W / S` |
| 转向 | `A / D` |
| 上/下车 | `Shift`（下车） |
| 切换视角 | `F5`（原版） |
| 自由视角 | `C` |
| 脱离相机 | `Ctrl`（默认，建议改到 `左 Alt`） |
| 手刹 | `空格` |
| 开火（载具武器） | `鼠标左键` |

⚠️ `Ctrl` 在 IV 里是"自由相机"，和 ParCool 的滑铲（如果没改）会撞。所以上面建议把 ParCool 滑铲放 `左 Ctrl`、IV 自由相机放 `左 Alt`。

### 语音（Simple Voice Chat）

| 功能 | 键 |
|---|---|
| 按键说话 | `鼠标侧键 1`（如果有）或 `V` |
| 语音菜单 | `鼠标侧键 2` 或 `N` |
| 静音 | `M` |

⚠️ SVC 默认 `V` 是语音菜单，TaCZ 默认 `V` 是检视。把 SVC 改到侧键，或者把 TaCZ 检视改到中键（上面已经这么做了）。

### 界面

| 功能 | 键 |
|---|---|
| 兵种切换 | `/bf6 class <id>` 命令 |
| 计分板 | 常驻 sidebar，不用按键 |
| 地图/模式菜单 | 大厅右键讲台 |

## 一次性改完的快捷方式

进游戏后打开 `.minecraft/options.txt`，把下面这些行替换掉（**先备份**）：

```
key_key.swapOffhand:F
key_key.drop:G
key_key.sneak:key.keyboard.left.shift
key_key.sprint:key.keyboard.left.alt
```

⚠️ 疾跑给**左 Alt**，不要给左 Ctrl —— 左 Ctrl 是 ParCool 的滑铲，
两个键撞一起会变成「按住跑不动、也滑不出去」。

三键分工：

| 键 | 归属 |
|---|---|
| 左 Shift | 原版潜行 |
| 左 Ctrl | ParCool 滑铲 |
| 左 Alt | 原版疾跑（同时是 IV 自由相机，进载具后由 IV 接管，不冲突） |

⚠️ `options.txt` 里 mod 的键位不在这里，还是得在游戏内改。上面 4 行只管原版。

---

## 键位保存与分发

改完后，把这两个文件发给朋友：

```
.minecraft/options.txt
.minecraft/config/parcool-client.toml     （ParCool 的键位在这里）
.minecraft/config/tacz-client.toml        （TaCZ 的键位在这里）
```

SVC 的键位在 `.minecraft/config/voicechat/voicechat-client.properties`。

这样三个人键位完全一致，不会出现"我按 R 换弹你按 R 换副手"的情况。
